# Swipe With Condition

## Description

Swipes on a specific element until a certain condition is met. ALWAYS return the index of the element that needs to be swiped as the elementIndex, and ALWAYS return the direction of the swipe in the metadata as one of the following: left, right, up, down. If the condition is not met, return the index of the element that needs to be swiped.

## Supported Engines

- Mobile

## Example Prompts

- swipe on the carrousel until the last card is visible
- swipe on the carrousel until the card with the text 'Bank of America' is visible
- swipe the carrousel until the card with the text 'Bank of America' is visible
- swipe on the products list until the last product is visible
- swipe on the promotions list until the shake shack promotion is visible
