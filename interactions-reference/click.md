# Click

## Description

This action needs to be selected in order to click an element. This action uses the image as well to determine if it makes sense to click the element. For example, if the user said "sign up" and there's a sign up button on the screen, they're probably trying to click sign up. However, if the user said "sign up" and there's no sign up button on the screen, it could be a case of bad usage because the user wanted to complete the sign up flow and you need to inform that.

## Supported Engines

- Web
- Mobile

## Example Prompts

- click on the login button
- click sign up
- login click
- click the eye button to see the password
- tap on delete
