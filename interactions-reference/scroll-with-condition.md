# Scroll With Condition

## Description

Scrolls elements into view, it can do it several times until the element is seen. Only select this if the user asks to scroll until it meets a condition , not a fixed amount of times (e.g. scroll down 2 times)

## Supported Engines

- Web
- Mobile

## Example Prompts

- scroll until the login button is visible
- scroll until the car is visible
- scroll until you reach the bottom of the page
