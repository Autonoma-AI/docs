# Long Press

## Description

This action performs a long press on an element. It intelligently handles both coordinate-based (from UI) and instruction-based (from text) long presses. When processing instructions, it uses visual object detection to find the target element. For example, if the user said "long press the login button" and there's a login button on the screen, it will detect and long press it.

## Supported Engines

- Web
- Mobile

## Example Prompts

- long press on the first item
- long press sign up
- long press the red heart icon
- long press on the profile picture
- long press the play button
- long press the eye button to see the password
- long press on delete
- long press element in the third row
- 'BUY NOW' long press
