# Double Tap

## Description

This action performs a double tap on an element. It intelligently handles both coordinate-based (from UI) and instruction-based (from text) double taps. When processing instructions, it uses visual object detection to find the target element. For example, if the user said "double tap the login button" and there's a login button on the screen, it will detect and double tap it.

## Supported Engines

- Web
- Mobile

## Example Prompts

- double tap on the login button
- double tap sign up
- double tap the red heart icon
- double tap on the profile picture
- double tap the play button
- double tap the eye button to see the password
- double tap on delete
- double tap the settings gear
- 'BUY NOW' double tap
