# Math Assert

## Description

Prefer this everytime you need to do a math calculation. An example might be the user asking if the sum of two values are equal to another value. Return the equation in string format on the metadata. Example: If the user sends "is ten plus 20 = thirty" the result should be "10 + 20 = 30". NEVER RETURN AN OBJECT AS METADATA.
