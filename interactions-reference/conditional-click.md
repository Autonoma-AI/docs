# Conditional Click

## Description

When the user prompts you with a condition, you need to click an element based on the condition. It's similar to a regular click, but operates optionally depending on the UI state and the condition the user provided. So if a condition its entered on the instruction we have to trigger this action.

## Supported Engines

- Web
- Mobile

## Example Prompts

- if there's a cookies button accept them
- close the modal if it's present
- si se muestra el cartel de notificaciones cerrarlo
- click the get started button if it's visible
- click the login button if it's visible
- si hay un modal de noticias nuevas cerrarlo
- if there's a modal of new news close it
