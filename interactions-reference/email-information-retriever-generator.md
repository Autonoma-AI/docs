# Email Information Retriever Generator

## Description

When asked to generate an email address for extracting information, generates an email address

## Supported Engines

- Web
- Mobile

- generate an email for otp
- generate an email for magic link
- email for account balance
- generate a mail for account number

- generate an email for account type
- generate an email for account balance
