# OCR Scroll

## Description

It uses OCR to locate a text element (for when you need to scroll a scrollable element), and then scrolls towards the direction needed. If the user asks to scroll a number of times, return that number on metadata. Otherwise metadata is 1. THE METADATA IS ALWAYS A NUMBER. NOT A STRING WITH A NUMBER.

## Metadata

Return the amount of times to scroll on metadata.

## Supported Engines

- Web
- Mobile

## Example Prompts

- ocr scroll up
- ocr scroll down 2 times
- ocr scroll left 3 times
