# Scroll

## Description

Scrolls elements into view. If an element is not completely in view, you need to scroll it into view. Otherwise, you will find unexpected behaviour. If the user asks to scroll a number of times, return that number on metadata. Otherwise metadata is 1. THE METADATA IS ALWAYS A NUMBER. NOT A STRING WITH A NUMBER.

## Metadata

Return the amount of times to scroll on metadata.

## Supported Engines

- Web

## Example Prompts

- scroll
- scroll down
- scroll up
