## What It Does

Move Carousel is a specialized mobile interaction designed for navigating horizontal carousels—those swipeable components common in mobile apps that display content in a side-by-side, scrollable format. Think Instagram stories, product image galleries, card-based payment methods, or promotional banner carousels.

Unlike general scrolling that moves vertically through a page, Move Carousel specifically handles horizontal swipe gestures on carousel-style UI components. It recognizes that carousels are distinct interaction patterns requiring precise horizontal navigation.

## When to Use It

Use Move Carousel when:

- **Horizontal card layouts** - Payment methods, saved addresses, profile cards
- **Image galleries** - Product photos, profile pictures, media galleries
- **Story feeds** - Instagram-style stories, news snippets, promotional stories
- **Promotional banners** - Marketing carousels at top of screens
- **Tabbed content** - Horizontally swipeable tab panels
- **Onboarding screens** - Tutorial slides that swipe left/right
- **Date pickers** - Horizontal scrolling date or time selectors
- **Category selectors** - Horizontally scrolling category chips or filters

**Don't use it when:**
- Scrolling vertically through content - Use **Scroll (Mobile)** instead
- Working on web applications - Use **Scroll (Web)** or other interactions
- Scrolling the main screen - Use **Scroll (Mobile)** instead
- Scrolling within nested containers - Use **OCR Scroll** instead

## Platform Support

- **Web**: No
- **Mobile**: Yes (iOS and Android only)

This is a mobile-specific interaction optimized for touch-based carousel navigation common in modern mobile applications.

## How It Works

Move Carousel simulates the horizontal swipe gesture that users naturally use to navigate carousels on mobile devices:

**Swipe left** (reveals content to the right):
```
Move carousel: left
```

**Swipe right** (reveals content to the left):
```
Move carousel: right
```

The interaction identifies carousel components through visual and structural analysis, then performs precise horizontal swipes to navigate between items.

## Left vs Right Navigation

Understanding carousel direction is crucial:

### Move Left (Swipe Left)
- **Reveals content to the right**
- Progresses forward through carousel items
- "Next" in the sequence
- Natural reading direction in most cultures

```
Move carousel: left
```

**Use for**:
- Moving to next story
- Viewing next product image
- Selecting next payment method
- Advancing through onboarding

### Move Right (Swipe Right)
- **Reveals content to the left**
- Goes back to previous carousel items
- "Previous" in the sequence
- Returning to earlier content

```
Move carousel: right
```

**Use for**:
- Going back to previous story
- Reviewing earlier images
- Returning to first payment option
- Backing up in tutorial flow

**Example using both directions**:

```
Test: "Navigate carousel bidirectionally"

1. Assert: First carousel item visible
2. Move carousel: left 5 times ← Move forward
3. Assert: Later items visible
4. Move carousel: right 3 times ← Move back
5. Assert: Earlier items visible again
```

## Common Patterns

### Pattern 1: Progressive Carousel Browsing

```
1. Assert: Carousel visible
2. Move carousel: left
3. Wait: 500ms
4. Assert: New item visible
5. Move carousel: left
6. Wait: 500ms
7. Assert: Next item visible
```

### Pattern 2: Find and Select

```
1. Move carousel: left 3 times
2. Wait: 500ms
3. Add prompt: "Click on the target item"
4. Wait until: Item selected
```

### Pattern 3: Complete Carousel Traversal

```
1. Move carousel: left 10 times ← Go through all items
2. Wait: 1 second
3. Assert: Reached end of carousel
4. Move carousel: right 10 times ← Return to start
5. Assert: Back at first item
```

### Pattern 4: Verify Carousel Length

```
1. Extract information: Count carousel items
2. Move carousel: left [count-1] times
3. Assert: Last item visible
```

### Pattern 5: Carousel Within Scrollable Content

```
// Scroll main screen to carousel
1. Scroll: down (swipe up) 3 times
2. Assert: Carousel visible

// Navigate carousel horizontally
3. Move carousel: left 5 times
4. Assert: Different carousel items visible
```

## Best Practices

### 1. Add Brief Waits After Each Move

Carousel animations need time to complete:

```
Good:
1. Move carousel: left
2. Wait: 500ms ← Let animation finish
3. Assert: New item visible

Risky:
1. Move carousel: left
2. Assert: New item visible ← Might check during animation
```

### 2. Verify Carousel is Visible First

Ensure the carousel has loaded:

```
1. Wait until: Screen loads
2. Assert: Carousel component visible ← Verify it's there
3. Move carousel: left 3 times
```

### 3. Don't Move Beyond Carousel Bounds

Carousels have finite items:

```
// If carousel has 5 items
Good:
1. Move carousel: left 4 times ← Moves through all items

Problematic:
1. Move carousel: left 20 times ← Might get stuck at end
```

### 4. Be Specific When Selecting Items

After moving, clearly identify what to select:

```
Good:
1. Move carousel: left 2 times
2. Add prompt: "Click on the Mastercard ending in 7890" ← Specific

Vague:
1. Move carousel: left 2 times
2. Add prompt: "Click the card" ← Which one?
```

### 5. Test Both Directions

Verify carousel works in both directions:

```
Test: "Bidirectional carousel navigation"

1. Move carousel: left 3 times
2. Assert: Forward navigation works
3. Move carousel: right 3 times
4. Assert: Backward navigation works
```

## Common Pitfalls

### Pitfall 1: Using Move Carousel for Vertical Scrolling

**Problem**:
```
1. Move carousel: down ← This doesn't exist!
```

**Why it fails**: Move Carousel only handles horizontal (left/right) navigation.

**Solution**:
```
1. Scroll: down (swipe up) ← Use Scroll for vertical movement
```

### Pitfall 2: Not Waiting for Carousel Animations

**Problem**:
```
1. Move carousel: left
2. Click: Item ← Item might be mid-animation
```

**Why it fails**: Carousel animations take time.

**Solution**:
```
1. Move carousel: left
2. Wait: 500ms ← Critical wait
3. Click: Item
```

### Pitfall 3: Moving Too Many Times

**Problem**:
```
// Carousel has 5 items
1. Move carousel: left 20 times ← Gets stuck at item 5
```

**Why it fails**: Can't move beyond the last item.

**Solution**:
```
1. Move carousel: left 4 times ← Just enough to see all items
Or better:
1. Move carousel: left 3 times
2. Check if target item visible
3. If not, move carousel: left 2 more times
```

### Pitfall 4: Using on Web Applications

**Problem**:
```
// Web application test
1. Move carousel: left ← Not supported on web
```

**Why it fails**: Move Carousel is mobile-only.

**Solution**:
```
// For web carousels
1. Click: "Next" arrow button
Or
1. Add prompt: "Click the right arrow to see next items"
```

### Pitfall 5: Confusing Direction

**Problem**:
```
// Want to see next item (to the right)
1. Move carousel: right ← This goes BACK to previous!
```

**Why it fails**: Swipe right reveals content on the LEFT.

**Solution**:
```
// To see next item (content on the right)
1. Move carousel: left ← Swipe left reveals right content
```

**Memory aid**: You swipe left to move left in the carousel sequence, revealing what's to the right visually.

### Pitfall 6: Not Distinguishing From Main Screen Scroll

**Problem**:
```
// Carousel exists, but using general scroll
1. Scroll: left ← Might not target carousel properly
```

**Why it's suboptimal**: Not specific to carousel behavior.

**Solution**:
```
1. Move carousel: left ← Explicitly targets carousel
```

## Performance Considerations

Carousel animations can affect test performance:

### Fast Consecutive Moves

```
// Less optimal - might skip items
1. Move carousel: left 5 times without waits

// Better - ensures each item is seen
1. Move carousel: left
2. Wait: 300ms
3. Move carousel: left
4. Wait: 300ms
5. Move carousel: left
6. Wait: 300ms
```

### Heavy Image Carousels

Carousels with large images need longer waits:

```
1. Move carousel: left
2. Wait: 1 second ← Longer wait for image loading
3. Assert: Image fully loaded
```

## Debugging Carousel Issues

If Move Carousel isn't working:

### Check: Is it actually a carousel?

```
1. Assert: Component has carousel structure
2. Assert: Multiple items visible or swipeable
3. Move carousel: left
```

### Check: Is the carousel loaded?

```
1. Wait until: Carousel component visible
2. Wait: 1 second ← Extra time for items to load
3. Move carousel: left
```

### Check: Direction confusion

```
// Want to see NEXT item (content to the right)
Correct: Move carousel: left
Incorrect: Move carousel: right
```

### Try: Slower navigation

```
1. Move carousel: left
2. Wait: 1 second ← Generous wait
3. Assert: Item changed
4. Move carousel: left
5. Wait: 1 second
```
