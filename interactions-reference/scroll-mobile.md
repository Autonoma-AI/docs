# Scroll

## Description

Scrolls elements into view. If an element is not completely in view, you need to scroll it into view. Otherwise, you will find unexpected behaviour. Also, consider that you are on a mobile device, meaning that to scroll down, you need to swipe up. So clarify both in metadata (scroll down + swipe up for example). If the user asks to scroll a number of times, return that number on metadata. Otherwise metadata is 1. THE METADATA IS ALWAYS A NUMBER. NOT A STRING WITH A NUMBER.

## Supported Engines

- Mobile

## Example Prompts

- scroll down
- scroll up
- scroll left
- scroll right
- swipe up
- swipe down
- swipe left
- swipe right
