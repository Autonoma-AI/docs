# Set File To Upload

## Description

Based on a user provided file in the file system, the file will be set on a special place in memory for uploading. Return only the path to look the file on the metadata.

## Metadata

Return only the path to look the file on the metadata.

## Supported Engines

- Web
- Mobile

## Example Prompts

- set the file /Users/tom/Downloads/test.pdf to upload
