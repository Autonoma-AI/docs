# Interactions Reference

This document provides a comprehensive reference for all available interactions in the Autonoma QA agent. Each interaction represents a specific action that can be performed on web or mobile applications during automated testing.

## Overview

Interactions are the building blocks of test automation in Autonoma. They allow you to simulate user actions, validate application state, and interact with UI elements across different platforms.

## Categories

Interactions are organized into the following categories:

- **Overview**: Basic operations like extracting data, using variables, conditional actions, email handling, waiting, and scrolling
- **Navigation & Movement**: Clicking, hovering, scrolling, navigation between pages
- **Input & Forms**: Text input, form submission, keypad input, file uploads
- **Testing & Validation**: Assertions, component usage
- **Device & Environment**: Camera mocking, network control, zoom
- **Advanced Actions**: API calls, conditional scrolling, email retrieval

## Usage

Each interaction guide includes:
- Description of what the interaction does
- Supported engines (Web, Mobile, or both)
- Example prompts that can trigger the interaction
- Any special metadata requirements

## Supported Engines

- **Web**: Browser-based applications
- **Mobile**: Native mobile applications (iOS/Android)

Some interactions are platform-specific, while others work across both environments.
