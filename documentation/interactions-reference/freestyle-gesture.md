# Freestyle Gesture

## Description

Allows users to drag from a location to another location. Choose this action when the user provides two locations to create the drag (from/to) and only two locaitons.

## Supported Engines

- Mobile

## Example Prompts

- drag from the top left corner to the bottom right corner
- drag from the whatsapp icon to the top right corner
- drag from the left of the carousel to the right of the carousel
