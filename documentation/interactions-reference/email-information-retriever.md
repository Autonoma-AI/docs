# Email Information Retriever

## Description

When the user asks for information from a the generated email, retrieves the information from the email. the user should provide information about what they want to extract from the email.

## Supported Engines

- Web
- Mobile

## Example Prompts

- retrieve the otp from the email
- retrieve the magic link from the email
- get the account balance from the email
- find the account number from the email
- find the account name from the email
- find the account type from the email
- find the account balance from the email
