# Assert URL Location

## Description

Asserts that the current matches the one passed by the user.

## Metadata

Return the url to match AND ONLY THE URL TO MATCH in metadata. It will be used directly wihtout any parsing so if you send any other data it will break.

## Supported Engines

- Web

## Example Prompts

- assert that the current url is https://autonoma.app
- assert that the current url is https://google.com
