# Input On Focus

## Description

Inputs text on the focused text without looking for the element. Only use this if explicitly told to. Otherwise, use input-text.

## Metadata

Return what needs to be inputted on metadata.

## Supported Engines

- Web
- Mobile

## Example Prompts

- input on focus the email on memory
- input on focus the password 123456
- input on focus tom@autonoma.app
