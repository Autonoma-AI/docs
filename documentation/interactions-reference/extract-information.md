# Extract Information

## Description

This action needs to be selected in order to extract visual information from the image that can be loaded to memory. This can be used later on the "get_memory" function. In case the value is empty or has no value just return an empty string (for example, you're asked to extract the information from an empty input field).

## Metadata

Return what needs to be extracted in metadata, or empty if the value is empty.

## Supported Engines

- Web
- Mobile

## Example Prompts

- extract the email from the image
- extract information about the balance from the image
- extract information about the amount of followers from the image
- extract the company name
