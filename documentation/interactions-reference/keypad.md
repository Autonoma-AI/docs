# Keypad

## Description

Choose this action IF AND ONLY IF there is a keypad on screen AND the user wants to input a number. If these conditions are met, prioritize this action over other interaction methods, unless the user specifically asks for input on focus.

## Metadata

Return the digits in the order they have to be pressed in the metadata

## Supported Engines

- Mobile

## Example Prompts

- type 3267 on the keypad
- input 123456 on keypad
- press 7 on the keypad
